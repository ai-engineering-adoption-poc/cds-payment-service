# Payment Service

The Payment Service handles payment requests generated by the Order Service.

## Responsibilities

- Validate payment requests
- Submit payment requests to the payment provider
- Record payment audit events
- Return payment status

## Security considerations

Payment credentials must never be stored directly by this application.

The application expects a payment token rather than raw card details.

Sensitive payment information must not be written to application logs.

## Dependencies

- Order Service
- External payment provider

## Technology

- Java 17
- Spring Boot
- Spring Security
- Maven
